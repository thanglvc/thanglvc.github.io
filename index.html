Training Fresher

Tổng hợp bài làm, mã nguồn, hình tham chiếu và tài liệu thực hành theo từng tuần.

Tuần 1 — HTML, CSS và JavaScript

  • Ngày 1 — Bài tập 1: Bài làm, Mã nguồn, Hình tham chiếu.
  • Ngày 1 — Bài tập 2: Bài làm, Mã nguồn, Hình tham chiếu.
  • Ngày 1 — Bài tập 3: Bài làm, Mã nguồn, Hình tham chiếu.
  • Ngày 2–3 — Product Detail (SHOP.CO): Bài làm, Mã nguồn, Hình desktop, Hình mobile, Figma.
  • Ngày 4 — Bài tập nâng cao 1 (Vận chuyển Nhật): Bài làm, Mã nguồn, Hình tham chiếu.
  • Ngày 4 — Bài tập nâng cao 2 (Thẩm mỹ / Clinic Nhật): Bài làm, Mã nguồn, Hình tham chiếu.

Tuần 2 — PHP, OOP và Laravel

Mini project quản lý sản phẩm và danh mục: API CRUD, phân trang và giao diện Laravel/Blade. Xem ảnh giao diện bên dưới hoặc làm theo hướng dẫn để chạy ứng dụng trên máy local.

  • Ngày 5 — Mini project: Mã nguồn, Hướng dẫn thực hành, Kiểm thử API bằng Pest.
  • Ảnh giao diện sản phẩm: Danh sách, Tạo mới, Chi tiết, Cập nhật.

Tuần 3 — Detail Design, testcase và AI workflow

Tài liệu chức năng theo pipeline raw spec → BD → DD/API và workflow → testcase → code.

  • Bộ tài liệu module sản phẩm và danh mục: Mục lục tài liệu.
  • Chức năng tạo sản phẩm: Raw spec, BD, DD và workflow, API specs, Testcase FE/BE.
  • Chức năng sản phẩm khác: Danh sách, Chi tiết, Cập nhật, Xóa, Tải danh mục.
